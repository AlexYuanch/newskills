# 实施与验证计划

依据已确认的 [设计](superpowers/specs/2026-11-02-conversation-skill-discovery-design.md) 实施。当前环境没有 writing-plans skill，使用此项目内计划承接。

1. 将 `.agents/skills/skill-scout` 作为单一维护来源，同步生成 Claude Code 入口；拆分项目分析、核验、宿主接入和评估说明。
2. 提供不落盘的决策 helper，约束真实用户证据、已具备能力、冷却、拒绝和同意；提供不使用 prompt 内容的共用 hook。
3. 提供默认只预览的项目级 hook 配置合并/移除工具，不修改本机全局设置。
4. 收紧现有扫描器：敏感配置只收集存在信息，忽略运行状态、二进制内容和符号链接，修复机器可读输出。
5. 更新 README、架构、隐私说明和来源记录；清理个人身份和被跟踪的运行状态；增加发布白名单、隐私检查和无历史导出。
6. 运行原有及新增行为测试、类型检查、构建、skill 同步检查和 npm 打包检查；用临时项目验证双宿主安装/移除；生成公开副本并复核归档内容。

验收边界：自动测试验证脚本、协议和规则；真实模型的语义识别和宿主 UI 内触发需按场景表另外验证，交付时不冒称通过端到端测试。

实现与自动验证已完成，结果见 [验证记录](verification.md)。
